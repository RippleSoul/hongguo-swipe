# 红果助手

**[下载 APK](https://github.com/RippleSoul/hongguo-swipe/releases/latest)**

1. 安装后点击「打开」，在系统无障碍中启用「红果助手」。
2. 返回红果看视频，遇到可上划的广告会自动上划。点击「已开启」可关闭。
3. 左上角菜单进入「睡眠」，选择倒计时或自动检测，到时停止播放并锁屏。

自动检测根据手机持续少动推测入睡，最短 15 分钟。自动上划支持 Android 7+，睡眠锁屏需要 Android 9+。

构建：准备 Python 3、JDK 17、Android SDK 33 / Build Tools 34.0.0，运行 `python3 build.py`。
